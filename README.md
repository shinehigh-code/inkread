# 墨读 InkRead

Windows 上的本地阅读器，电子书和漫画都能看。文件只从本机读取，程序不联网，不需要账号，也没有任何在线功能。

支持的文件：

| 类型 | 格式 |
| --- | --- |
| 电子书 | TXT、Markdown、EPUB |
| 漫画 | CBZ、ZIP、CBR、RAR、CB7、7Z、CBT、TAR；也可以直接选一个装满图片的文件夹 |

## 能做什么

**看小说**：打开 TXT 后自动判断编码（UTF-8、GBK、Big5、UTF-16），按「第 N 章」「序章」「番外」这类标题自动分章。翻页和滚动两种模式随时切换，读到哪里会自己记住。

**看笔记和电子书**：Markdown 的标题、表格、代码块、图片按原文排版，数学公式用内置的 KaTeX 离线渲染；EPUB 能读目录、封面和插图，书里的内链可以点。

**看漫画**：单页或双页并排，可以按高度、按宽度、按原始尺寸显示，长条漫可以连续滚动。页序支持从左到右和从右到左。

**听书与选词**：用 Windows 自带的语音逐句朗读，读到哪一句哪一句高亮，翻页模式会自动翻页、滚动模式会自动滚动，一章读完接着读下一章。语速、音调、音量都能调，也支持暂停和跳句。选中正文后还可以直接朗读、复制，或用内置基础词库做离线中英互译；未收录的专名和复杂句式会保留原文，不会上传文字。

**隐私阅读**：从侧栏点「隐私阅读」临时打开文件。该文件不会加入书架，不保存进度和书签；隐私 EPUB 的临时解析目录会在退出阅读或程序结束时清理。

**繁体**：顶栏下拉随时切换原文、简体、繁體、繁體（台湾）、繁體（香港）。转好的结果按章缓存，来回翻章不用重新转。

**找东西**：书库支持搜索、按最近阅读或书名排序，网格和列表两种视图。单本书里可以全文搜索，点结果直接跳到那一段并高亮。

## 界面

五套主题：纸、墨、茶、苔、夜（夜是纯黑）。字体、字号、字重、行距、页宽、段距都在阅读设置里调，改完立刻生效。底部把「章节跳转」和「章内进度」分开：左右按钮快速换章，滑块只调整当前章内的页码或滚动位置。

TXT 和 Markdown 没有封面图，程序会按书名生成一张排版封面，不是灰色占位图。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `←` `→` / `空格` / `PgUp` `PgDn` | 翻页（漫画按阅读方向自动对应） |
| 鼠标滚轮 | 翻页模式下翻页（连续滚动模式下就是滚动） |
| `Ctrl+F` | 本书内搜索 |
| `+` `-` | 字号增减 |
| `F11` | 全屏 |
| `Esc` | 返回书架 |

## 窗口操作

只有顶部可以拖动窗口：窗口标题栏，以及阅读器的顶部工具栏。正文里拖动是选中文字，底部栏拖动是调进度条，都不会把窗口拖走。拖窗口边缘或四角可以缩放，最小 960×600；双击标题栏最大化或还原。

阅读时鼠标停住不动，工具栏会自动收起，动一下鼠标就回来。阅读设置面板打开的时候，点正文只会收起面板，不会把工具栏一起藏掉。

## 打开文件的方式

装好后在资源管理器里右键电子书 →「打开方式」→「选择其他应用」→ 选 `墨读.exe`，勾上「始终使用」。之后双击这类文件就直接进阅读界面。

窗口已经开着时再打开另一个文件，会在当前窗口里切过去，不会多开一个进程。也可以把文件拖到 `墨读.exe` 图标上，或者用命令行：

```
墨读.exe "D:\书\某本.epub"
```

一次传多个文件时，打开第一个，其余的加进书库。

## 从源码运行

```bash
pip install -r requirements.txt
python main.py                 # 普通启动
python main.py 某本书.epub      # 直接打开指定文件
```

打包成单文件 exe：

```bash
python build.py                # 产物 dist/墨读.exe
```

## 数据与隐私

- 书库、进度、书签、设置默认存在 `%APPDATA%\InkRead\`，运行日志是同目录的 `inkread.log`
- 「隐私阅读」中的文件不写入书架、进度或书签；隐私 EPUB 使用系统临时目录解析，退出后自动清理
- 设置环境变量 `INKREAD_HOME` 可以改成便携模式，数据跟着程序走
- 界面由本机 `127.0.0.1` 上的临时端口提供，只在回环地址监听，外部访问不到。程序只读本机文件，不发起任何外网请求，也不上传任何内容
- 运行期间会在数据目录写一份 `instance.json`，只记录进程号和本地端口，用来把「再次打开的文件」交给已经在跑的窗口；退出时自动删除
- EPUB 和 Markdown 里的 HTML 一律按白名单净化：脚本、样式、事件属性会被剥掉，外链图片置空
- 压缩包只按条目名读取或解压到自己的缓存目录，路径越界（Zip Slip）直接拒绝
- 书里的外部链接交给系统浏览器打开，不在阅读器里跳转

## 已知限制

- `.cbr` / `.rar` 需要系统里有 UnRAR（装 WinRAR 会自带）或 `unar`。没有的话会明确提示，不会静默失败
- 加密压缩包暂不支持
- 不解析 PDF、MOBI、AZW3。PDF 建议用专门的阅读器

## 目录结构

```
main.py              入口：起本地服务 + pywebview 窗口
build.py             打包脚本
app/
  server.py          本地 HTTP 服务与全部 API
  library.py         书库、进度、书签、封面缓存
  handlers.py        TXT / MD / EPUB / 漫画四种格式解析
  textproc.py        编码识别、章节分割、繁简转换、HTML 净化
  translate.py        选中文字的离线基础中英互译
  api.py              原生对话框与窗口控制
  win32.py           窗口最大化、还原、缩放、置顶
  diag.py            进程内自检（排查卡死用）
  config.py          路径与常量
web/                 前端（原生 HTML/CSS/JS，没有构建步骤）
samples/             样例书与测试脚本
tools/make_icon.py   生成应用图标
tools/publish.py     发布到 GitHub
```

## 测试

```bash
python samples/make_samples.py         # 生成样例书（GBK 小说、Big5 繁体、MD、EPUB、CBZ、7Z、图片文件夹）
python samples/smoke_test.py           # 后端接口，46 项
python samples/test_cli_open.py        # 「用墨读打开」链路，7 项（加 --exe 测打包版）
python samples/run_dev.py              # 开发模式：起服务并导入样例
node samples/test_features.js <端口>   # 界面交互（需要 Playwright + 系统 Edge），29 项
```
