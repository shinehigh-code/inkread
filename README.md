# 墨读 InkRead

Windows 本地电子书与漫画阅读器。装得下的格式都能读，界面按纸质书的路子做：纸感底色、衬线正文、克制的分隔线。

替代记事本看小说，也替代一堆只认单一格式的小工具。

## 功能

**书库**

- 添加文件或整个文件夹（文件夹按图片文件夹当漫画导入）
- 封面网格 / 列表两种视图，搜索、按最近阅读 / 书名 / 添加时间排序
- TXT、Markdown 没有封面图，自动生成排版封面
- 自动记录阅读进度，书架顶部给一张「继续阅读」卡片

**阅读（TXT / MD / EPUB）**

- 翻页（左右分栏）与滚动两种模式，随时切换；翻页模式支持鼠标滚轮翻页
- 主题五套：纸 / 墨 / 茶 / 苔 / 夜（含纯黑）
- 字体（宋体、楷体、黑体、雅黑、Georgia）、字号、行距、页宽、段距全部可调
- 目录、书签、全文搜索（结果可直接跳转并高亮）
- **语音朗读**：用系统语音逐句朗读，当前句高亮并自动跟随（翻页模式自动翻页、滚动模式自动滚动）；可暂停/继续、跳句、调语速/音调/音量；本章读完自动续读下一章
- Markdown 支持表格、代码块、图片，数学公式用随包内置的 KaTeX 渲染（离线可用）
- EPUB 解析目录（nav / NCX）、封面、内链跳转、插图

**漫画（CBZ / CBR / CB7 / CBT / 图片文件夹）**

- 单页 / 双页，适应高度 / 适应宽度 / 原始大小 / 连续滚动（条漫）
- 从左到右、从右到左两种阅读方向

**繁简转换**

- 顶栏下拉随时切换：原文 / 简体 / 繁體 / 繁體（台湾）/ 繁體（香港）
- 转好的文本按章节缓存，翻章不卡

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `←` `→` / `空格` / `PgUp` `PgDn` | 翻页（漫画按阅读方向自动对应） |
| 鼠标滚轮 | 翻页模式下翻页（连续滚动模式下为滚动） |
| `Ctrl+F` | 本书内搜索 |
| `+` `-` | 字号增减 |
| `F11` | 全屏 |
| `Esc` | 返回书架 |

窗口：只有标题栏和阅读器工具栏可以拖动（在正文里拖动是选中文字，不会误拖窗口）；拖窗口边缘或四角可以缩放大小（最小 960×600）；双击标题栏最大化 / 还原。阅读时鼠标停住不动，工具栏自动隐去；动一下鼠标就回来。阅读设置面板打开时点正文只会收起面板，不会把工具栏一起藏掉。

朗读：点顶栏的喇叭图标开始（从当前看到的句子起读），底部出现迷你控制条；语音、语速、音调、音量在阅读设置面板里调。语音取自 Windows 系统，离线可用，想更自然可在「设置 → 时间和语言 → 语音」里添加语音包。

## 运行

已装好的直接双击 `墨读.exe`。

从源码跑：

```bash
pip install -r requirements.txt
python main.py
```

打包单文件 exe：

```bash
python build.py        # 产物 dist/墨读.exe
```

## 数据与隐私

- 书库、进度、书签、设置默认存在 `%APPDATA%\InkRead\`，运行日志同目录下 `inkread.log`
- 设环境变量 `INKREAD_HOME` 可改为便携模式，数据跟着走
- 界面由本机 `127.0.0.1` 上的临时端口提供（仅回环，外部访问不到），只读取本机文件，程序本身不发起任何网络请求，不上传任何数据
- EPUB / Markdown 内的 HTML 一律白名单净化：脚本、样式、事件属性会被剥掉，外链图片置空（离线阅读，顺带防跟踪）
- 压缩包只按条目名读取或解压到自己的缓存目录，路径越界（Zip Slip）直接拒绝
- 外部链接一律交给系统浏览器打开，不在阅读器内跳转

从源码运行时，终端可能打印一批 pywebview 的 WinForms / WebView2 提示（形如 `Error while processing window.native...`），那是它内部的属性反射日志，不影响功能；打包后的 exe 无控制台，不会看到。

## 已知限制

- `.cbr` / `.rar` 需要系统里有 UnRAR（WinRAR 安装目录自带）或 `unar`；没有的话会明确提示，不会静默失败
- 加密压缩包暂不支持
- 不解析 PDF、MOBI、AZW3（PDF 建议用专门阅读器）

## 目录结构

```
main.py              入口：起本地服务 + pywebview 窗口
build.py             打包脚本
app/
  server.py          本地 HTTP 服务与全部 API
  library.py         书库、进度、书签、封面缓存
  handlers.py        TXT / MD / EPUB / 漫画四种格式解析
  textproc.py        编码识别、章节分割、繁简转换、HTML 净化
  api.py             原生对话框与窗口控制
  config.py          路径与常量
web/                 前端（原生 HTML/CSS/JS，无构建步骤）
samples/             示例书与测试脚本
tools/make_icon.py   生成应用图标
```

测试：

```bash
python samples/make_samples.py     # 生成样例书（GBK 小说、Big5 繁体、MD、EPUB、CBZ、7Z、图片文件夹）
python samples/smoke_test.py       # 后端 29 项检查
python samples/run_dev.py          # 开发模式：起服务并导入样例
```
